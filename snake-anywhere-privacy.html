Snake Anywhere Privacy Policy

Chrome extension · Last updated 27 October 2026

Snake Anywhere lets you play Snake as a transparent overlay on the web page you are viewing. This policy explains what the extension does and does not do with your data. The short version: it collects nothing.

Data we collect

None. Snake Anywhere does not collect, transmit, sell or share any personal data, browsing data or page content. The extension makes no network requests of any kind.

Data stored on your device

The extension saves a small amount of information locally in your browser using Chrome's chrome.storage.local API:

  • Your high score for each website, keyed by the site's hostname (for example example.com), so your best score is shown the next time you play there.
  • Whether you have turned on the "dim page" option.
  • A flag recording that the one-time controls hint has already been shown.

This data never leaves your device. It is not synced to any server, is not visible to the developer, and is deleted when you uninstall the extension. You can also clear it at any time from Chrome's extension settings.

Permissions

  • activeTab: lets the game run on the tab you are viewing, only after you click the icon or press Alt+S.
  • scripting: injects the game's own files into that tab so the overlay can be drawn.
  • storage: saves the local data described above.

No host permissions are requested. The extension cannot access any page until you explicitly start the game on it, and it does not read, modify or record page content while the game is running.

Remote code

All code ships inside the extension package. No code is downloaded or executed from external sources.

Children

The extension is suitable for all ages and collects no data from anyone.
